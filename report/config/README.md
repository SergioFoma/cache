# Конфигурации кешей

`<алгоритм>_<ёмкость>.json` задаёт одноуровневый кеш для каждой ёмкости из отчёта: 10, 25, 50, 75, 100, 125, 150, 175 и 200. Имена алгоритмов: `LRU`, `ARC`, `2Q`, `LFU`, `LIRS`. JSON соответствует формату `ConfigJson` из проекта.

`LRU20_*.json` задаёт первый уровень LRU ёмкостью 20 и второй уровень ARC, 2Q, LFU или LIRS ёмкостью 80. Порядок элементов массива `cache` соответствует порядку уровней, начиная с первого.

`<алгоритм>.txt` содержит конфигурацию для текущего исполняемого файла `cache` (`-f`): число уровней и название алгоритма. Ёмкость для этого формата берётся из первой строки входного датасета, поэтому один TXT-конфиг подходит для всех 320 последовательностей. Для опытов с ёмкостью, отличной от 100 следует заменить первое число в копии датасета. Текущий `src/main.cpp` использует только `ConfigTxt`; JSON-конфиги предназначены для кода, использующего `ConfigJson`.

Белади не задаётся конфигом иерархии: реализация требует всю последовательность запросов заранее.
