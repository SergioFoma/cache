# Результаты измерений

`measurements.csv` содержит 18 560 запусков: 320 последовательностей × 58 конфигураций (45 одноуровневых, четыре двухуровневые и Белади при девяти ёмкостях). `summary.csv` содержит средние результаты, выборочную дисперсию (п. п.²) и стандартное отклонение (п. п.) по 40 последовательностям каждого вида нагрузки. Первые 5000 запросов прогревают кеш; доля попаданий рассчитана для следующих 20 000 запросов. Каждый запуск начинается с пустого кеша.

`full_mixed_measurements.csv` содержит 19 000 запусков двухуровневого кеша для всех 25 упорядоченных пар алгоритмов и 19 разбиений ёмкости с шагом 5 %, а также 160 запусков Белади. `full_mixed_summary.csv` содержит средние показатели 475 конфигураций.

После изменения датасетов запустите измерение и обновите сводки, иначе сохранённые доли попаданий будут относиться к прежней нагрузке. Параметры эксперимента приведены в [отчёте](../REPORT.md). Основные измерения выполняет `report/code/measure.cpp`, сводку строит `report/code/summarize_results.py`, графики — `report/code/plot_results.py`. Полный перебор двухуровневых конфигураций и его сводку создаёт `report/code/full_mixed_sweep.py`.
